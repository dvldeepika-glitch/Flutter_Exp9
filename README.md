# Flutter Experiment 9: Fetching Data from a REST API

## Aim

To develop a Flutter application that fetches and displays data from a REST API.

## API Used

https://jsonplaceholder.typicode.com/posts

## Technologies Used

* Flutter
* Dart
* REST API
* JSON
* HTTP package

## Features

* Fetches posts from a REST API.
* Converts JSON responses into Dart objects.
* Displays posts in a scrollable list.
* Shows post details if implemented.
* Handles loading and network errors if implemented.

## Project Structure

* `lib/` – Flutter application source code.
* `outputs/` – Screenshots of the application output.
* `pubspec.yaml` – Project dependencies and configuration.

## Output

The application fetches posts from the JSONPlaceholder API and displays them in the Flutter interface.

## Conclusion

The experiment demonstrates how to retrieve and display REST API data in a Flutter application.
